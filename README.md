One line, in the office printer's own voice, as its comeback to the jams, the
cryptic error codes and the thumps. Entry for the
[make.fun competition "The Printer Finally Answers"](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907).

## The line

> ERROR 0x51: PAPER JAM. CAUSE: 47,213 SHEETS, ZERO THANK-YOUS, NINE THUMPS. I AM NOT BROKEN. I AM KEEPING SCORE.

## How it works

`main.ts` writes that single line (111 characters) to `/output/entry.txt`.
Nothing else is read, fetched or executed. Run it with Node 22.18+:

```sh
node main.ts
```
